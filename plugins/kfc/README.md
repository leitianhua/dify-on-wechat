# KFC 疯狂星期四文案生成插件

这是一个用于生成随机疯狂星期四文案的插件。

## 功能特点

- 支持多个触发关键词
- 随机生成疯狂星期四文案
- 文案来源于在线API

## 使用方法

发送以下任一关键词即可获取随机疯狂星期四文案：
- 肯德基
- kfc
- KFC
- 疯狂星期四

## 配置说明

您可以自定义触发关键词：

1. 编辑 `config.json` 文件
2. 修改 `kfc_keyword` 数组，添加或删除您想要的关键词

示例配置：
```json
{
    "kfc_keyword": ["肯德基", "kfc", "KFC", "疯狂星期四", "V我50"]
}
```

## 安装说明

1. 将插件目录放在 `plugins` 目录下
2. 重启机器人即可使用

## 示例输出

```
v我50，我给你转8块8，这是我的诚意，V了的话我再v你50，不V我继续想法设法的V你，直到你V我，v了我立马v你，不要问为什么，kfc疯狂星期四v我50
```

## 注意事项

- 插件依赖网络API，如遇到网络问题可能会导致获取文案失败
- 文案内容随机生成，与实际品牌无关
- 请勿将文案用于商业用途
