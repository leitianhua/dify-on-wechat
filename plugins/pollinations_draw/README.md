# Pollinations AI 绘图插件

一个集成 Pollinations.AI API 的画图插件，支持自定义参数和模型切换。

## 功能

- 图像生成：调用 Pollinations 的图像生成API
- 查询模型：查看可用的图像模型列表
- 切换模型：设置当前会话的默认图像生成模型
- 自定义参数：支持自定义图像尺寸、种子值等参数
- 随机生成：不指定参数时自动随机选择模型、尺寸和种子值

## 使用方法

### 图像生成

使用以下前缀命令生成图像：
```
p画 [提示词]
p生成图片 [提示词]
```

可以添加参数：
```
p画 [提示词] 模型:flux 宽度:512 高度:768 随机种子:42
```

不添加参数时，将随机选择模型、尺寸和种子值。

### 查看模型列表

使用以下命令查看可用模型：
```
p模型
```

该命令会显示当前正在使用的默认模型，以及所有可用的模型列表。

也可以搜索特定模型：
```
p模型 sd
```

### 切换默认模型

使用以下命令切换当前会话的默认模型：
```
p切换模型 [模型名称]
```

例如：
```
p切换模型 kandinsky
```

注意：切换的模型设置仅在当前会话中有效，重启程序后将恢复为配置文件中的默认设置。

## 参数说明

可以在提示词中添加以下参数：
- `模型:xxx` - 设置使用的模型
- `宽度:xxx` - 设置图像宽度
- `高度:xxx` - 设置图像高度
- `随机种子:xxx` - 设置随机种子，控制图像生成的随机性
- `无水印:true/false` - 是否去除水印，默认为true

## 配置说明

在 `config.json` 中可以配置以下内容：

```json
{
    "image_prompt_prefix": ["p画", "p生成图片"],
    "list_models_prefix": ["p模型"],
    "model_switch_prefix": ["p切换模型"],
    "random_generation_enabled": true,
    "default_image_model": "flux"
}
```

- `image_prompt_prefix`: 图像生成命令前缀
- `list_models_prefix`: 查看模型列表命令前缀
- `model_switch_prefix`: 切换默认模型命令前缀
- `random_generation_enabled`: 是否启用随机生成功能（不指定参数时随机选择）
- `default_image_model`: 默认使用的图像生成模型
